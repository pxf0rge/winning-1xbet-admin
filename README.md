## 🌟 Key Features / قابلیت‌های کلیدی

### English
- Odds & match event creation
- Bet slip audit & settlement
- User balance & ledger controls
- Supabase live database sync

### فارسی
- تعریف رویدادهای ورزشی و تنظیم ضرایب
- بررسی و تسویه خودکار شرط‌ها و تیکت‌ها
- مدیریت حساب و موجودی کاربران
- همگام‌سازی بلادرنگ با دیتابیس Supabase

## 🚀 Getting Started / راه‌اندازی پروژه

### Prerequisites
- Flutter SDK (>= 3.0.0)
- Dart SDK
- Android Studio / VS Code with Flutter extension

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pxf0rge/winning-1xbet-admin.git
   cd winning-1xbet-admin
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the application:**
   ```bash
   flutter run
   ```
